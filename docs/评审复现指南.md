# 评审复现指南（5 分钟）

> 目的：让评委或第三方在不安装任何云端服务的前提下，5 分钟内独立验证本项目声称的核心指标。
> 全部命令在 Windows + PowerShell 下执行；也可在 Linux 下等价运行（把路径改为仓库路径）。

## 0. 环境准备（一次性）

```powershell
# 需要 Python 3.11+（含 numpy），以及本机已安装 FreeCAD（提供 freecadcmd）
# 本项目实测使用：Python 3.12.11 / numpy / fastapi / uvicorn / FreeCAD 1.1.4
$py = "python"          # 换成你的解释器路径
cd D:\hyperdesign2\backend
$env:PYTHONPATH = "D:\hyperdesign2\backend"
```

若 FreeCAD 不在默认路径，设置：

```powershell
$env:HD_FREECAD_CMD = "C:\你的路径\FreeCAD 1.1\bin\freecadcmd.exe"
```

## 1. 验证「几何确定性」（约 20 秒）

```powershell
& $py D:\hyperdesign2\scripts\m0_gate.py
```

期望关键输出：

| 指标 | 期望 |
|---|---|
| 体积偏差 | `0.0000%` |
| 包络 | `120.0 x 80.0 x 45.0` |
| 底面 | `Z_min = 0.000` |
| 实测拔模 | `min_draft_deg = 1.8`，`vertical_face_count = 0` |
| 恶意 IR | `execute_script` 被拒绝 |

## 2. 验证「规则可审计」（约 10 秒）

```powershell
& $py D:\hyperdesign2\scripts\m1_gate.py
```

看三点：每条规则是否带 `citation.document` 与 `citation.clause`；指标缺失是否判 `invalid`；
注入 `eval` 算子的规则包是否在加载期被拒绝。

## 3. 验证「审批门不可绕过」（约 15 秒）

```powershell
& $py D:\hyperdesign2\scripts\m2_gate.py
```

看三点：物理判不通过时审批节点是否 `skipped`；事件 `seq` 是否单调；重复 `run_id` 是否被拒。

## 4. 验证「仿真与理论解对标」（约 10 秒）

```powershell
& $py D:\hyperdesign2\scripts\m4_gate.py
```

期望：梁挠度/弯矩误差 `0.0000%`；圆孔应力集中系数 `Kt = 3.128`（理论 3.0）。

## 5. 验证「设计空间可行性与自动修复」（约 60 秒，含两次几何建模）

```powershell
& $py D:\hyperdesign2\scripts\m7_gate.py
```

期望：`R=3.0` 判不可行（内角半径 −0.82mm）→ 修复为 4.1mm → 重建通过；
以及同一引擎构建 CNC 支架（80×40×44mm）并用支架规则包通过。

## 6. 验证「知识资产与拒答」（约 15 秒）

```powershell
# 先起服务
Start-Process $py -ArgumentList "D:\hyperdesign2\backend\app\api\server.py"
Start-Sleep 8
& $py D:\hyperdesign2\scripts\m5_gate.py
```

期望：三角色可见 1/6/7 篇；无关查询 `found=false`。

## 7. 打开交互界面

浏览器访问 `http://127.0.0.1:8010`：

1. 选择「合规链路」→ 运行 → 三维区显示实体与包络 `120.00 × 80.00 × 45.00`；
2. 切「规则取证」→ 19 条规则逐条带文档与条款；
3. 切「知识库」→ 角色选「访客」再检索 → 显示「无证据」提示；
4. 右上「审批」→ 通过 → 状态变 `succeeded`。

## 常见问题

- **没有 FreeCAD**：M0/M1/M2/M4/M5/M7 中的几何用例会失败，但规则引擎、工作流、知识库、仿真的单元用例仍可跑通（m1 的规则加载用例不依赖内核）。
- **端口占用**：`HD2_PORT=8011` 后再启动服务。
- **中文乱码**：PowerShell 执行前设置 `$env:PYTHONIOENCODING="utf-8"`。
