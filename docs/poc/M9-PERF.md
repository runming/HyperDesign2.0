# M9 性能测量报告 · 2.0 平台层端到端

- 方法：连续 3 次运行 6 节点工作流，取中位数（`scripts/m9_perf.py` 可复跑）
- 结论：平台层端到端 **2461.4 ms**，3 次波动 **4.2%**

| 节点 | 内容 | 中位耗时 (ms) |
|---|---|---|
| n1_cad_build | IR 构建（几何内核建模 + 校验） | 2133.3 |
| n2_cad_harness | CAD 几何准入（10 条规则） | 0.4 |
| n3_mesh_dfm | 网格物理准入（6 条规则） | 0.0 |
| n3b_cae | CAE 有限元（1152 单元） | 320.9 |
| n3c_cae_harness | CAE 准入（3 条规则） | 0.0 |

合计（中位）：**2461.4 ms**

## 与 1.0 的对照

| 环节 | 1.0 | 2.0 |
|---|---|---|
| 参数化建模 + 几何校验 | 465.8s（LLM 生成代码后执行，每次重跑） | 2.13s（确定性执行）+ 准入 0ms |
| 工艺检索与铁律校验 | 75.9s（整段大模型推理） | 0.02s 检索 + 毫秒级规则判定 |

> 说明：本表只测量 2.0 平台层；概念图与三维重建属 1.0 生成式能力层，需 GPU 环境，不在本脚本范围。
> 1.0 的数字取自 `progress.log` 时间戳，可回溯核对。
