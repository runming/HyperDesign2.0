## 三、构建中修掉的真实缺陷

1. **西文字体错误导致英文渲染成希腊字母**：最初把 `w:ascii` 也设为 仿宋_GB2312，渲染时 `AIGC`→`ΑΓΓΧ`、`CAD`→`ΣΑΔ`。
   修正为 中文 eastAsia=仿宋_GB2312、西文 ascii/hAnsi/cs=Times New Roman（中文公文标准做法），渲染后英文与缩写完全正确。
2. **表格单元格去重误判**：`id(cell._tc)` 会因 lxml 代理对象被回收而复用，导致不同单元格被判为同一格，
   使"核心技术"勾选漏掉两项。改为用集合持有元素引用的方式去重后恢复正常。
3. **外文全称不足**：初稿缺 RAG 与 FEM 的全称展开，已补为「检索增强生成，Retrieval-Augmented Generation，RAG」
   与「有限元（Finite Element Method，FEM）」。
