# M17 门禁报告 · DXF 工程图（尺寸 + 公差标注）

- 结论：**通过**
- 模块：`backend/app/caddraw/dxf_writer.py`（R12 ASCII，**自带写出器，无第三方依赖**）
- 公差来源：`app/standards/tables.py`（GB/T 1800.1 标准公差，IT9）

| 门禁 | 结果 | 证据 |
|---|---|---|
| D1 DXF 可解析且四图层齐备 | ✅ | 实体 34 个，图层 ['CUT_PROFILE', 'DIMENSIONS', 'HIDDEN_LINE', 'TITLE_BLOCK'] |
| D2 外轮廓为 1:1 真实尺寸 | ✅ | outline_mm=[120.0, 80.0]（来自 CAD-IR 参数） |
| D3 尺寸文本含公差且取自标准表 | ✅ | IT9：120→87µm、80→74µm；文本样例=['120.0 %%p0.087', '80.0 %%p0.074'] |
| D4 孔位数量（1 导光孔 + 4 安装柱） | ✅ | holes=5，CUT_PROFILE 圆=5 |
| D5 标注不混入切割层 | ✅ | CUT_PROFILE 文本=0，DIMENSIONS 文本=3 |
| D6 标题栏含实测体积与包络 | ✅ | 体积 67510.058mm³、包络 {'x': 120.0, 'y': 80.0, 'z': 45.0} |

## 图层分工

| 图层 | 用途 | 图元 |
|---|---|---|
| CUT_PROFILE | 1:1 激光切割/CNC 外轮廓，直接进 CAM | LINE×4, CIRCLE×5 |
| HIDDEN_LINE | 内腔与不可见边（虚线） | LINE×4 |
| DIMENSIONS | 尺寸线 + 尺寸文本（含公差） | LINE×7, TEXT×3 |
| TITLE_BLOCK | 图框标题栏（材料/壁厚/拔模/公差等级/实测） | LINE×7, TEXT×4 |

## 与常见做法的差异

- 常见导出：只出轮廓线，公差与配合信息丢失，质检仍需人工补标；
- 本实现：按配合/尺寸自动查 GB/T 1800.1 公差表并写入尺寸文本，同时把实测体积与包络写进标题栏，图纸可回溯到具体运行。

> 实测指标：体积 67510.058mm³，包络 {'x': 120.0, 'y': 80.0, 'z': 45.0}。
